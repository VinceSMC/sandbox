# Build Guide

| # | Area | Purpose |
|---:|------|---------|
| 1 | [Village](areas/village.md) | The main settlement containing most buildings, services, merchants, and villagers. |
| 2 | [Mining District](areas/mining-district.md) | The main location for mining-related services and the Blacksmith. |
| 3 | [Mob Camp](areas/mob-camp.md) | A dedicated area for mob-related content. |
| 4 | [Combat Settlement](areas/combat-settlement.md) | The main location for combat services, equipment, and enchanting. |
| 5 | [The Forest](areas/the-forest.md) | The main location for woodcutting, foraging, and wood-related merchants. |
| 6 | [Farm](areas/farm.md) | The main location for crops, animals, and farming-related content. |
| 7 | [Fishing Forest](areas/fishing-forest.md) | A water-rich forest dedicated to fishing-related content. |
| 8 | [Mountain](areas/mountain.md) | A dedicated mountain area. Its exact gameplay purpose has not yet been defined. |
