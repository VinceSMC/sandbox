# Lumberjack's House

**Structure type**
<br>`Lumberjack's House`

**Area**
<br>[The Forest](../areas/the-forest.md)

**Description**
<br>Forms the main wood and foraging location within The Forest. It should contain the Lumberjack and their quests, the Lumber Merchant, and the Carpenter.
<br>The location should feel like a small woodworking cluster rather than a single isolated house. Additional workshops, storage, or supporting structures can be added around the Lumberjack's House so all three NPC roles feel naturally connected. The exact number and arrangement of these structures is still open.
