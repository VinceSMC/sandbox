# The Library

**Structure type**
<br>`The Library`

**Area**
<br>[Combat Settlement](../areas/combat-settlement.md)

**Description**
<br>Allows players to enchant and upgrade items. It also houses a merchant who sells enchantments.
<br><br>Place the Library inside the Combat Settlement and develop it together with the Armory. Both structures should share a coherent architectural language, scale, palette, and surrounding environment while remaining visually distinct. How much of the current Library is retained is still open.
