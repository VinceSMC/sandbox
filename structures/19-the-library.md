# The Library

**Structure type**
<br>`Library`

**Area**
<br>[Combat Settlement](../areas/combat-settlement.md)

**Description**
<br>Allows players to enchant and upgrade items. It also houses a merchant who sells enchantments.
<br>The Library belongs inside the Combat Settlement and should be developed together with the Armory. Both structures should share a compatible architectural style, scale, palette, and surrounding environment while remaining visually distinct. How much of the current Library is retained is still open.
