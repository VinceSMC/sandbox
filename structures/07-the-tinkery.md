# The Tinkery

**Structure type**
<br>`Tinkery`

**Area**
<br>[Village](../areas/village.md)

**Description**
<br>Houses two NPCs. The Engineer manages the Gem Reactor, which generates Gems over time and can be upgraded for greater production speed and storage capacity. Gearson sells Booster Capsules that grant players special abilities.
<br>The exterior is approved and should remain largely unchanged. The interior would benefit from more detail and a stronger workshop atmosphere. A visible Gem Reactor machine should become the main interior feature, with a clear area for each NPC.
