# Resource Foundry

**Structure type**
<br>`Resource Foundry`

**Area**
<br>[Village](../areas/village.md)

**Description**
<br>Allows players to convert one resource into another. For example, Island EXP can be converted into Upgrade Tokens used to upgrade their island.
<br>The current structure provides a solid base, but it could use a more distinctive identity. Showing parts of the conversion process within the design would help communicate its purpose. The preferred direction is to combine it with The Bar in one larger building while keeping separate entrances and visual identities for both features.
